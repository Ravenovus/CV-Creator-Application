# CV Creation Application
A basic CV creation application built in React.\
Created as part of The Odin Project full stack developer curriculum\
No AI was used in its production.

## Vercel Deployed Link:
https://cv-creator-application-top.vercel.app/

## Features:
CV creation featuring 3 sections, Introduction, Education and Experience.\
Includes live-time updates as information gets inserted as a preview for the CV.\
Submit and Edit functionality on each section separately.

## Technology used
- React JSX
- CSS
- Vite
